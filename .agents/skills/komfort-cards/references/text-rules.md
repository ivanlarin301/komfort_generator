# Правила текстов карточки

Главное: **текста минимум, товар — главный**. Только ключевое для покупки. Шрифты, размеры и цвета задаёт шаблон — пиши только содержание.

Эталоны владельца:
- Canva «К: РЕМОНТ» — база: https://canva.link/wje926uukoyhv9m
- Canva «К: УЛИЦА» — вариации: https://canva.link/19fvetfh275n1z0

## Блоки сверху вниз

| Блок | Поле | Что писать | Примеры из эталона |
|---|---|---|---|
| Заголовок | `title` | Тип товара, при уместности бренд в «ёлочках». Лучше до 24 символов — тогда помещается крупно в одну строку. Максимум 40 | «Грунтовка концентрат», «Плита «Теплекс»», «Клей GERMIX GM-245 PRO», «Гипсокартон «Knauf»» |
| Акцент | `title_accent` | Часть заголовка, обычно бренд, — выделится зелёным. Необязательно | «Helpfer» в «Тачка «Helpfer»» |
| Строка-подзаголовок | `subtitle` | Одно-два слова уточнения, белым без плашки | «Теплоизоляционная», «Садово-строительная» |
| Белая плашка | `badge` | 1–2 строки: модель, серия, объём или назначение. `**жирное**` выделяет значение | ««Dekoral» 10 л.», «Для керамогранита и тёплого пола», «грузоподъемность **250 кг**» |
| Иконки-свойства | `features` | 0–3 штуки, только если свойство важно для покупки. Ключ иконки — из `config/icons.yaml`, текст до 24 символов | `{"icon": "diameter", "text": "диаметр **100 мм**"}` |
| Плашка параметра | `plate` | Одно ключевое число и подпись | «25 кг / фасовка», «20х585х1185 / размеры», «10 л / объём», «180 л / объём барабана» |

## Как выбирать

- **Не повторяй одно свойство дважды.** Если «250 мл» стоит на плашке параметра, в белой плашке его быть не должно.
- **Одного подзаголовка обычно достаточно**: либо строка, либо белая плашка. Оба сразу — только для крупных товаров, как «Тачка» в эталоне.
- **Иконки** нужны для свойств, которые не видны на фото: морозостойкость, расход, время высыхания, мощность. Не ставь иконку ради украшения.
- **Цвет плашки параметра** (`plate.style`):
  - `green` — по умолчанию;
  - `white` — если товар или фон зелёные и зелёная плашка с ними сольётся.
  
  Значок «+» (`plate.plus`) обычно оставляем. Для однословной плашки без числа («одноколёсная») — `"label": ""` и `"plus": false`.
- **Единицы — по-русски, с пробелом:** «25 кг», «10 л», «250 мл», «850 Вт», «Ø 100 мм», «20х585х1185».
- **Регистр не важен** — шаблон сам делает заглавные. Пиши обычным регистром.

## Источники данных

Порядок обращения:
1. таблица оператора;
2. надписи на упаковке на фото;
3. страница товара на komfort.kz по коду;
4. общие знания — только для слов без чисел, например «для внутренних работ».

Числа без подтверждения из источников 1–3 не выводим. В `sources` укажи источник для каждого заполненного блока: `title`, `subtitle`, `badge`, `plate`, `features`.

## Категория фона (`category`)

| Ключ | Когда |
|---|---|
| `dry_mix` | сухие смеси, клеи для плитки, штукатурки, наливные полы |
| `paint` | краски, эмали, грунтовки, лаки |
| `boards` | утеплитель, плиты, гипсокартон, OSB, фанера, кровля |
| `sealants` | герметики, монтажная пена, клей в тубах и баллонах |
| `tools` | инструменты и оборудование, бетономешалки |
| `ventilation` | вентиляция и сантехника |
| `garden` | сад, огород, грунты, садовый инвентарь, тачки |
| `outdoor` | отдых, пикник, бассейны, надувные товары |
| `auto` | автохимия |
| `home` | посуда, интерьер, товары для дома |
| `default` | если ничего не подходит |
