# Прототип шаблона (одобряется владельцем по итерациям, 2026-10-01)

`card-v7.html` — текущая проба дизайн-слоя, база для TSK-003.

Что в пробе по сравнению с эталоном Canva:
- градиенты сверху и снизу — точные значения из Canva;
- трекинг заголовка −0.02em — по замечанию владельца;
- логотип — из файла `assets/logo.png`;
- цена крупнее, по просьбе владельца +20–30%: в пробе 114 px. В рабочем шаблоне — 110 px с правым краем 933, как владелец сам делает в «К: УЛИЦА»;
- зелёная плашка повторяет схему Canva — круговой радиальный градиент, сплошной в центре, прозрачный к углам. Прозрачнее эталона (88% → 50% вместо 100% → 63.5%), без размытия, рамки и тени — по просьбе владельца, «как на клее», стр. 52;
- товар ниже: зазор до белой плашки не меньше 60 px; небольшой заход под зелёную плашку допустим.

Только для пробы: товар «запечён» в старый фон, поэтому вниз сдвинуто всё фото. Верхняя щель закрыта размытой копией фона (`.bg-fill`). В рабочем шаблоне товар — отдельный слой, и этот приём не нужен.

Файл ссылается на `bg.png` и `logo.png` рядом с собой и на Google Fonts. В рабочем шаблоне шрифты подключаются локально из `assets/fonts/`.
