# Прототип шаблона (одобрен владельцем 2026-10-01)

`card-v4.html` — проба дизайн-слоя, по которой владелец одобрил раскладку. Это база для TSK-003.

Что в пробе по сравнению с эталоном Canva:
- градиенты сверху и снизу и радиальная заливка зелёной плашки — точные значения из Canva;
- трекинг заголовка −0.02em — по замечанию владельца;
- логотип — из файла `assets/logo.png`;
- цена крупнее на 25%: 114 px вместо 91, по просьбе владельца.

Файл ссылается на `bg.png` и `logo.png` рядом с собой и на Google Fonts. В рабочем шаблоне шрифты подключаются локально из `assets/fonts/`.
