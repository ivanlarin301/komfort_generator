# Карточки «Комфорт»

Система делает карточки товаров для Instagram в фирменном дизайне «Комфорта», как в Canva.
- **Что нужно дать:** фото товаров и таблица с кодами и ценами.
- **Что получится:** готовые картинки 1080×1350 с названием, плашками, кодом, ценой и логотипом.

Работа идёт в программе **Codex**:
- Codex читает таблицу и рисует фон под каждый товар;
- товар берётся с вашего фото без искажений;
- дизайн всегда одинаковый: его собирает шаблон, а не нейросеть.

---

## 1. Установка (один раз на компьютер)

Нужно: Windows 10 или 11, интернет, приложение **Codex** со входом в ваш аккаунт ChatGPT.

1. **Получите папку проекта** и положите её **близко к корню диска**, например `D:\Комфорт`. В глубоких папках вроде «Загрузки\…\…» Windows может не справиться с длинными путями.
   - Если владелец дал архив (ZIP) — распакуйте его туда.
   - Если на компьютере есть Git — выполните `git clone <адрес репозитория> D:\Комфорт`.
2. Откройте папку и **дважды щёлкните `УСТАНОВКА.bat`**.
   - Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
   - Подождите 5–15 минут. В конце появится зелёная надпись **ГОТОВО**.
   - Если появилась красная **ОШИБКА**, запустите установку ещё раз. Не помогло — отправьте владельцу файл `setup.log` из этой папки.
3. Откройте **Codex** → откройте проект → выберите эту папку.

## 2. Как сделать карточки

1. В Codex, в этой папке, начните **новый чат**.
2. Прикрепите **фото товаров** и **таблицу** (файл Excel или скриншот) **в том же порядке**: первое фото = первая строка таблицы, второе = вторая и так далее.
3. Напишите: **«Сделай карточки»**.
4. Codex покажет, как он понял таблицу и фото. **Проверьте коды и цены** и ответьте **«да»**. Если что-то не так — напишите, что исправить.
5. Дождитесь отчёта: где лежат карточки и какие стоит проверить.

Хорошие фото:
- товар целиком, на белом фоне, крупно (от 1000 пикселей);
- без коробок, людей и надписей рядом.

## 3. Где готовые карточки

В папке `output\<дата_время>\`:
- `01_<код>.png`, `02_<код>.png` … — готовые карточки;
- `preview.jpg` — все карточки партии на одной картинке, удобно проверить серию.

## 4. Если что-то пошло не так

| Что видите | Что сделать |
|---|---|
| Codex пишет «Не вижу фото» | Прикрепите фото ещё раз. Или положите файлы в папку `input` под номерами `1.jpg`, `2.jpg` … и напишите «фото в папке input» |
| «Фото: 4, а ожидалось 5» | Проверьте, что прикреплены все фото и порядок совпадает с таблицей |
| Карточка «на проверку» | Codex напишет причину. Можно попросить: «переделай карточку 3: сделай текст короче» |
| «Система не установлена» | Запустите `УСТАНОВКА.bat` |
| Любая другая ошибка | Перешлите владельцу текст ошибки и файл `setup.log` |

## 5. Обновление

Дважды щёлкните **`ОБНОВЛЕНИЕ.bat`**.
- Если проект ставили через Git, обновление скачается само.
- Если из архива — скачайте свежий архив у владельца и распакуйте поверх. Папки `output` и `input` не трогайте.
