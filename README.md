# Komfort: агент для генерации карточек товаров

Этот репозиторий содержит **агентную систему**, а не товарные данные: навык Codex, правила работы, скрипты скачивания фотографий и создания выходного Excel. Рабочие Excel-каталоги, фотографии и готовые карточки остаются на каждом компьютере локально и в GitHub не отправляются.

## Первый запуск на новом компьютере

### 1. Установите программы

- [Git](https://git-scm.com/downloads)
- Python 3.11 или новее
- приложение Codex и войдите в свой аккаунт OpenAI

### 2. Скачайте агентную систему

Откройте PowerShell в папке, где хотите хранить проект, и выполните:

```powershell
git clone https://github.com/bnvspace/komfort_maket_master.git Komfort
cd Komfort
```

### 3. Установите зависимости для скачивания фотографий

В той же папке выполните:

```powershell
python -m pip install -r requirements.txt
python -m playwright install chromium
```

Это делается один раз на каждом новом компьютере. Если Python запускается через команду `py`, замените `python` на `py`.

### 4. Откройте папку в Codex

В приложении Codex выберите открытие локального проекта и укажите папку `Komfort`, созданную командой `git clone`.

Отдельно устанавливать навык не нужно. Codex автоматически видит локальный навык в папке:

```text
.agents/skills/marketplace-product-cards/
```

Чтобы вызвать его явно, начните сообщение с:

```text
Используй $marketplace-product-cards ...
```

Но обычно достаточно написать задачу обычными словами: навык подхватится сам.

## Как начать новый каталог

1. Скопируйте Excel-файл с товарами в корневую папку `Komfort`.
2. Создайте новый чат **внутри этого проекта** в Codex.
3. Отправьте один из примеров ниже.

Для автоматического скачивания фотографий Excel должен содержать колонки **«Код АХ»** и **«Наименование»**. Если в нём есть ссылки на товары или фотографии, они также сохраняются в отчёте, но не обязательны для старта.

## Готовые промпты

### Сначала посмотреть каталог, ничего не создавать

```text
Используй $marketplace-product-cards. Проанализируй Excel «каталог.xlsx»: проверь товары и доступные исходные фотографии, предложи группы для карточек. Ничего не генерируй.
```

### Создать карточки для всего Excel

```text
Используй $marketplace-product-cards. Создай коммерческие карточки 4:5 для всех товаров из Excel «каталог.xlsx». Если локальных фотографий нет, сначала скачай доступные с товарных страниц. Не останавливайся на товарах без фото: отметь их как blocked, обработай остальные и создай выходной Excel со ссылками на исходники и карточки.
```

### Создать карточки только для нескольких товаров

```text
Используй $marketplace-product-cards. В Excel «каталог.xlsx» создай карточки только для товаров с кодами 12345, 67890 и 13579. Остальные позиции не трогай.
```

### Продолжить после добавления фотографии вручную

Сначала положите файл в папку:

```text
images/<точное наименование товара>/
```

Затем в том же или новом чате напишите:

```text
Используй $marketplace-product-cards. Я добавил фотографии для товара «точное наименование». Продолжи запуск для Excel «каталог.xlsx»: обработай только ранее заблокированные или незавершённые позиции.
```

### Проверить уже созданные карточки, не перегенерируя

```text
Используй $marketplace-product-cards. Проведи аудит карточек для Excel «каталог.xlsx»: сравни их с исходными фото, перечисли несоответствия и позиции needs_review. Ничего не перегенерируй.
```

### Переделать конкретную карточку

```text
Используй $marketplace-product-cards. Переделай карточку товара с кодом 12345 из Excel «каталог.xlsx». Сохрани форму, цвет, материал и ключевые детали товара; сделай более светлый нейтральный интерьер без текста, цен, логотипов и посторонних товаров. Создай новую версию, старую не удаляй.
```

### Обновить выходной Excel со ссылками

```text
Используй $marketplace-product-cards. Обнови выходной Excel для «каталог.xlsx»: сохрани исходную книгу без изменений и создай её копию со статусами, ссылками на папки и исходные фотографии, а также ссылками на готовые карточки.
```

## Что произойдёт в процессе

1. Агент создаст отдельный запуск для конкретного Excel.
2. Проверит локальные фотографии в `images/<наименование товара>/`.
3. Для позиций без фото попробует получить изображения скриптом с товарной страницы.
4. Создаст карточки 4:5 для позиций с подтверждёнными фото.
5. Сохранит результат и выходную копию Excel в отдельной папке запуска.

Карточки разных Excel не смешиваются:

```text
output/product-cards/<имя-Excel-без-расширения>/
  manifest.json
  <имя-Excel>_с_карточками.xlsx
  cards/<наименование товара>/
```

В выходном Excel добавляются статус карточки, папка исходных фото, список исходных файлов, ссылка на первое исходное фото, папка карточки и ссылка на готовую карточку.

## Когда у товара нет фотографии

Если сайт не отдаёт подтверждённую фотографию, товар получает статус `blocked`, а остальные позиции продолжают обрабатываться. Найдите фото сами и положите его в:

```text
images/<точное наименование товара>/
```

После этого отправьте промпт «Продолжить после добавления фотографии вручную» из раздела выше.

## Обновление агентной системы

Чтобы получить улучшения, в терминале открытого проекта выполните:

```powershell
git pull
```

Изменения самой агентной системы, которые делает Codex в этом проекте, коммитятся и отправляются в ветку `main` автоматически. Локальные каталоги, фотографии и готовые карточки в GitHub не попадут.
