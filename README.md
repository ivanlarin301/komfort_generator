# Komfort: генерация карточек товаров

Проект принимает Excel-каталог товаров, автоматически получает доступные исходные фотографии и создаёт коммерческие карточки 4:5 через навык Codex `marketplace-product-cards`. Репозиторий хранит только агентную систему; рабочие Excel, изображения и результаты не отправляются в GitHub.

## Как продолжить на другом компьютере

1. Установите Git, Python 3.11+ и Codex.
2. Клонируйте репозиторий и откройте его папку в Codex.
3. В терминале проекта выполните:

   ```powershell
   python -m pip install -r requirements.txt
   python -m playwright install chromium
   ```

4. Создайте новый чат в этом проекте, прикрепите или поместите Excel в корень и напишите, например: «Сгенерируй карточки для этого Excel».

Codex применит локальный навык из `.agents/skills/marketplace-product-cards/`.

## Где лежат результаты

Каждый Excel создаёт самостоятельный запуск:

```text
output/product-cards/<имя-Excel-без-расширения>/
  manifest.json
  <имя-Excel>_с_карточками.xlsx
  cards/<наименование товара>/
```

Выходной Excel — копия исходного: в ней добавлены статусы и ссылки на локальные исходные фотографии и готовые карточки. Исходные Excel и папка `images/` не изменяются.

## Если фотография отсутствует

Скрипт пробует скачать фотографии с товарной страницы по коду. Если получить их нельзя, позиция отмечается `blocked`, а остальные товары продолжаются. Положите найденное фото в `images/<наименование товара>/` и напишите в чате: «Фото добавил, продолжай».
