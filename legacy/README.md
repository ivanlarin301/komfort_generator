# Архив: старый поток (Excel со ссылками → карточки без текста)

Здесь лежит прежняя система. С 2026-10-02 она не используется: Codex её не видит, потому что её нет в `.agents/skills/`.

- `marketplace-product-cards/` — старый навык Codex. Генерировал карточку целиком нейросетью, без текста и цен.
- `download_images.py` — скачивание фото с komfort.kz по коду из Excel.
- `parse_images_to_excel.py` — сбор ссылок на фото в Excel.

Почему заменена: шрифты и цвета на карточках разъезжались, на кадре появлялись артефакты, а цены и код нейросеть вообще не ставила. Новая система описана в `.kiro/specs/canva-style-cards/`, навык — `.agents/skills/komfort-cards/`.
